# راهنمای به‌روزرسانی پروفایل بهار افشاری

این مستند نحوه استفاده از اسکریپت خودکار برای تکمیل اطلاعات پروفایل بهار افشاری و آکادمی زیبایی ایشان را شرح می‌دهد.

## زمان اجرا
این اسکریپت باید **بعد از بالا آمدن کانتینرهای دیتابیس** و اعمال Migrationها اجرا شود.

## نحوه اجرا

### روش اول: اجرا از داخل کانتینر (توصیه شده)
اگر پروژه شما با Docker در حال اجراست، از این دستور استفاده کنید:

```bash
docker compose exec api npx ts-node scripts/update_bahar_profile.ts
```

### روش دوم: اجرا در محیط توسعه (Local)
اگر دیتابیس در حال اجراست و می‌خواهید مستقیم از سیستم خودتان اجرا کنید:

۱. ابتدا مطمئن شوید وابستگی‌ها نصب هستند:
```bash
npm install
```

۲. اجرای اسکریپت:
```bash
npx ts-node scripts/update_bahar_profile.ts
```

---

## جزئیات اسکریپت

### ۱. فایل داده‌ها (`scripts/beauty_images.json`)
این فایل شامل ۲۰ آدرس تصویر با کیفیت بالا از Unsplash است. اسکریپت به صورت خودکار ۵ تصویر اول را برداشته و در دیتابیس به عنوان آواتار، کاور و تصاویر گالری پروفایل بهار افشاری ثبت می‌کند.

### ۲. اسکریپت اجرایی (`scripts/update_bahar_profile.ts`)
این اسکریپت موارد زیر را انجام می‌دهد:
- **تخصص‌ها:** ایجاد تخصص‌های "میکاپ عروس"، "آموزش"، "شینیون" و غیره.
- **کاربر:** ایجاد یوزر با نام کاربری `baharaafshari`.
- **پروفایل آرتیست:** ثبت بیوگرافی و اطلاعات تماس بهار افشاری.
- **سالن:** ثبت "آکادمی زیبایی بهار افشاری" با آدرس کامل (الهیه، فرشته).
- **تیم:** افزودن ۴ متخصص دیگر به لیست کارکنان سالن.
- **تصاویر:** آپلود و لینک کردن تصاویر به پروفایل.

## شخصی‌سازی
اگر نیاز به تغییر آدرس یا شماره تماس دارید، می‌توانید متغیرهای داخل فایل `scripts/update_bahar_profile.ts` را ویرایش کرده و مجدداً اسکریپت را اجرا کنید. این اسکریپت هوشمند است و اطلاعات قبلی را فقط بروزرسانی می‌کند (دیتای تکراری نمی‌سازد).

## تایید نهایی
پس از اجرا، می‌توانید با مراجعه به پنل ادمین (`/backoffice`) یا فراخوانی API زیر، صحت اطلاعات را چک کنید:
`GET /api/v1/artists/bahar-afshari`
